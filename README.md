# 🍫 CHOCO CRAFT - Landing Page & Fulfillment System

ระบบหน้าร้านขายช็อกโกแลตแท่ง (2 SKUs) เชื่อมต่อฐานข้อมูล Google Sheets พร้อมหน้าพนักงานสำหรับหยิบสินค้า แพ็คพัสดุ และพิมพ์ใบจ่าหน้า

## โครงสร้างไฟล์
- `index.html` — หน้า Landing Page สำหรับลูกค้าสั่งซื้อสินค้า
- `admin.html` — หน้าหลังบ้านสำหรับดึงออเดอร์มาหยิบสินค้า แพ็ค และพิมพ์ใบจ่าหน้าพัสดุ
- `images/dark-75.jpg` — รูปภาพสินค้า SKU-01 (75% Single Origin Dark Chocolate)
- `images/milk-hazelnut.jpg` — รูปภาพสินค้า SKU-02 (Milk Chocolate Hazelnut Crunch)
